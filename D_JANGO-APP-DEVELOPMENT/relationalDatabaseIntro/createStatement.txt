Lecture Notes: The CREATE TABLE Statement
1. Introduction to the CREATE TABLE Statement
Classification: CREATE is a Data Definition Language (DDL) statement used to define, build, and modify database structures (entities/tables).

Purpose: Defines a new relational table, including its column names, data types, and optional constraints (such as primary keys and nullability constraints).

2. Syntax of the CREATE TABLE Statement
Basic Structure:

SQL
CREATE TABLE table_name (
    column1_name datatype constraints,
    column2_name datatype constraints,
    ...
);
Formatting Rules:

Statement starts with CREATE TABLE followed by the table name.

Column definitions are enclosed within parentheses ().

Each column definition includes the column name, data type, and optional constraints.

Individual column definitions are separated by commas.

3. Basic Example: Provinces Table
Statement:

SQL
CREATE TABLE provinces (
    id CHAR(2) PRIMARY KEY NOT NULL,
    name VARCHAR(24)
);
Data Types Used:

CHAR(2): Fixed-length character string of exactly 2 characters (e.g., province codes like AB, BC).

VARCHAR(24): Variable-length character string holding up to 24 characters (e.g., full names like ALBERTA, BRITISH COLUMBIA).

4. Elaborate Example: Author Table
Based on the Library database, creating a table for the AUTHOR entity with specific constraints:

Statement:

SQL
CREATE TABLE author (
    author_id CHAR(2) PRIMARY KEY NOT NULL,
    lastname VARCHAR(15) NOT NULL,
    firstname VARCHAR(15) NOT NULL,
    email VARCHAR(40),
    city VARCHAR(15),
    country CHAR(2)
);
Constraints Explained:

PRIMARY KEY: Assigned to author_id to uniquely identify each row (tuple) and prevent duplicate entries in the table.

NOT NULL: Applied to author_id, lastname, and firstname to enforce that these fields cannot be left empty (a NULL value is prohibited because an author must have a name and an ID).

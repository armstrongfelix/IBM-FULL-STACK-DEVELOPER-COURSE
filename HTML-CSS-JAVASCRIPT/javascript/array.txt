Introduction to Arrays in JavaScript
Learning Objectives

Describe the fundamental concepts of arrays in JavaScript.

Examine common use cases and methods for working with arrays.

Fundamental Concepts
Definition: A data structure used to store, organize, and group a collection of related values.

Data Types: Arrays can store various data types, including numbers, strings, objects, or even other arrays.

Ordered & Zero-Indexed: Elements are stored in a specific sequence and are accessible by their index (position). The first element is at index 0, the second at index 1, and so on.

Creating and Accessing Arrays
Creation: Declare an array using square brackets with elements separated by commas (e.g., an array named fruits containing apple, banana, and cherry).

Accessing Elements: Use the element's index to retrieve or store its value.

Example: Accessing index 0 retrieves apple, and accessing index 1 retrieves banana.

Array Properties and Mutability
Length Property: Use the length property to determine how many elements are inside the array (e.g., a three-item array returns a length of 3).

Mutability: Arrays can be modified after creation. You can change, add, or remove elements at any time.

Example: Assigning strawberry to index 2 replaces the existing third element (cherry).

Built-in Array Methods
JavaScript includes a variety of built-in methods to perform operations on arrays:

push: Adds a new element to the end of the array (e.g., adding orange to the end).

pop: Removes the last element from the array (e.g., removing cherry from the end).

Other common methods: shift, unshift, splice, slice, concat, map, and filter.

Multidimensional Arrays
Arrays can be nested inside other arrays to create complex, multidimensional data structures.

Matrix Example: A single array containing three subarrays, where each subarray represents a row in a matrix.

Purpose: Highly useful for handling and processing two-dimensional data in algorithms and applications.

Iteration and Common Use Cases
Iteration: You can iterate through array elements to process data using standard for loops or modern array methods like forEach, map, filter, and reduce.

Common Tasks:

Storing lists of items.

Iterating through collections of data.

Implementing data structures like stacks and queues.

Managing data in tables and grids.

Two-Dimensional NumPy Arrays
While NumPy can be used to build arrays of much higher dimensions, this section focuses specifically on 2D arrays.

1. Basics and Array Creation in 2D
Creation: You can create a 2D NumPy array by casting a list that contains nested lists of equal size.

Visualization: It is helpful to visualize a 2D NumPy array as a rectangular array or matrix, where each nested list corresponds to a different row.

Attributes:

ndim (Rank): Returns the number of axes or dimensions. In a 2D array, think of this as the number of nested lists. The first list represents the first dimension, and the lists contained within it represent the second dimension (axis).

Note: The term "rank" here refers to dimensions, not the number of linearly independent columns as in traditional linear algebra.

shape: Returns a tuple indicating the size of the array in each dimension.

The first element corresponds to the number of rows (nested lists). This is conventionally labeled axis 0.

The second element corresponds to the number of columns (the size of each nested list). This is conventionally labeled axis 1.

size: Returns the total number of elements in the array (calculated by multiplying the number of rows by the number of columns).

2. Indexing and Slicing in 2D
You use rectangular brackets [] to access different elements of the array. The first index always corresponds to the row index, and the second corresponds to the column index.

Double Bracket Indexing: [row_index][column_index]

The first bracket accesses the specific nested list (row).

The second bracket accesses the particular element within that nested list (column).

Single Bracket Indexing: [row_index, column_index]

Accomplishes the same thing using a comma to separate the row and column targets (e.g., specifying the second row and the third column to find a specific value).

3. Basic Operations in 2D
Array Addition: Identical to matrix addition.

It adds the elements that are in the exact same position together.

The result is a new matrix of the exact same size.

Scalar Multiplication: Identical to multiplying a matrix by a scalar.

If you multiply a matrix by a scalar (like 2), you simply multiply every element in the matrix by that number.

The result is a new matrix of the same size.

Hadamard Product (Element-wise Multiplication):

Multiplies the elements that share the exact same position in two different arrays together.

The result is a new matrix of the same size where each element is the product of the corresponding elements in the original arrays.

Matrix Multiplication:

Rule: To multiply Matrix A by Matrix B, the number of columns in Matrix A must be equal to the number of rows in Matrix B.

Process: To obtain the element for a specific row and column in the new matrix, you take the dot product of that row from Matrix A and that column from Matrix B.

Example: To find the value for the first row and first column of the new matrix, take the dot product of the first row of A and the first column of B.

This can be performed directly using NumPy arrays, outputting a new array that corresponds to the standard matrix multiplication of the two original arrays.

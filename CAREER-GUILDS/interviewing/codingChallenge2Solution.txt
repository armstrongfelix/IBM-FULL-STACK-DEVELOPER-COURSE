Javascript Solution

function removeDuplicates(arr) {
  var usedItems = [];
  arr.forEach(function(item){
    if (!usedItems.includes(item)){
      usedItems.push(item);
    }
  });
  return usedItems;
}

Python Solution

def removeDuplicates(arrlst):
    result = []
    for item in arrlst:
        if item not in result:
            result.append(item)
    return result

Procedure
In the above code:

We first defined a function called removeDuplicates which would take input as an array.
The input variables can contain any number of strings or integers.
We create an empty array to hold the new array that will contain non-duplicate items.
We iterate through the array.
We compare each item of the array to the items in the new empty array. If it doesn’t exist in the new array, we push this item. If the item exists, the code would ignore it and go to the next array item.
In JavaScript, we use inbuilt push function.
